開始安裝 檢查版本

首次安裝

新版安裝包可雙擊 開始安裝.cmd 完成本機授權，不需右鍵選擇 PowerShell；Chrome 擴充功能仍須手動載入。如 Apex One 阻擋，請先檢查警告內容，不要關閉防護。

請依照下列步驟安裝 Windows Beta 2。

01

下載安裝包

下載 MediaSaver 所需檔案，解壓縮到固定資料夾。

02

安裝 Chrome 擴充功能

開啟擴充功能管理頁，依照圖文教學載入未封裝項目。

03

安裝本機程式

執行下載包內的本機安裝器，完成必要的 Windows 設定。

04

測試連線

確認 Chrome 與 MediaSaver 本機程式能正常通訊。

檢查安裝資料夾（Windows / Chrome）

先將安裝包解壓縮，再選擇解壓後的 MediaSaver 資料夾。網站只會檢查檔名是否存在；不會上傳檔案，也不會執行安裝。

尚未選擇資料夾。

新版固定 ID 安裝包：請選外層「MediaSaver 新朋友安裝包」。網站會自動偵測內層擴充功能資料夾，資料夾名稱不必固定。

支援兩種結構：擴充功能四個檔案放在根目錄，或集中放在同一個子資料夾（不限子資料夾名稱）；四個 EXE 保持在根目錄。安裝後本機執行檔會複製到使用者自己的 AppData；Chrome 未封裝擴充功能資料夾仍不可任意搬移，否則需要重新載入擴充功能。此檢查無法證明 EXE 安全或已正確安裝。

本次為 Windows Beta 2 預先發布版，安裝前請檢查 GitHub Release 來源與安全軟體警告。 請勿下載其他來源宣稱為 MediaSaver 的安裝檔。 不需要關閉防毒軟體或防火牆。
